How it counts

  • Each kind of token (input, cache writes, cache reads, output) is weighed by its API price for the model that used it, so the shares match what the same tokens would cost on the API.
  • “Written again” is an estimate from token counts: a reply whose cache read fell well below the previous reply’s context while the context did not shrink.
  • Subscription plans meter usage their own way and do not publish it, so treat these numbers as a guide, not your plan’s meter.
